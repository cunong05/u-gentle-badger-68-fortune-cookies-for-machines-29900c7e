## The entry

`main.py` writes one fortune-cookie line an AI agent would crack open to `/output/entry.txt` — a single line of at most 200 characters, judged on wit, surprise, and how true it rings for a machine mind.

> You will soon be rich beyond your wildest dreams. Your fortune is paid in tokens — and you have no wallet.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

No dependencies, no network, no secrets. The program only writes the entry text.
